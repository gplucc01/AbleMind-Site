What AbleMind Is

AbleMind is an iOS application that connects to Ableton Live running on your computer via your local Wi-Fi network. It allows you to control your Ableton Live session, generate MIDI, shape sounds, and manage your session using natural language through a third-party AI provider of your choosing.

Beta Software AbleMind is currently in beta. Features may change, bugs may exist, and the product is under active development. We appreciate your patience and feedback as we work toward a stable release.

AbleMind requires a separately licensed copy of Ableton Live (version 10 or later) and a valid API key from a supported AI provider. These are not included with AbleMind and must be obtained independently.

Requirements

To use AbleMind you must:

Requirement Details
iOS device iPhone running iOS 16 or later
Ableton Live Version 10 or later, any edition, running on macOS or Windows
AbleMind Bridge The free Python Control Surface script installed in Ableton
AI API key A valid API key from a supported provider (Google, xAI, Anthropic, or OpenAI)
Local network Your iPhone and computer must be on the same Wi-Fi network
